## Current runtime and rights

The current version uses a real Quaternius skinned runner with separate animation
clips, Kenney trains/rails/obstacles/buildings, trimmed/normalized local WAV sound
and a CC0 music loop. It is not the procedural-only prototype described in the
historical README sections. Full provenance and bundled notices are retained in
[THIRD_PARTY.md](THIRD_PARTY.md) and the shipped license folder.

`npm run audit:assets` checks the actual 64-entry runtime manifest, GLB structure,
model dependency paths, a real skeleton, 11 required animation names, WAV payloads,
fonts and license files. It does not rely on pack marketing names.

The local deterministic QA/debug hooks (`window.__metro`) are now restricted to
localhost/loopback; the public game has no exposed god-mode/collision helper.
Gameplay and art have not been changed for hosting.

Watch this project's Vercel deployment status, then check the public site. Do not
force-push or deploy from the multi-app workspace root. Build tools do not need
asset-inbox or the full source packs; regenerating art/audio intentionally does.
Cloud builds run unit/asset/build gates; browser QA runs separately, not on Vercel.

## Saved progress and testing boundaries

Best score, coin totals and preferences live in each browser's localStorage.
Localhost saves do not move to the hosted origin; no cloud sync is added. Clearing
site data can remove those saves. Audio starts after a real input gesture and is
not recorded or uploaded. The game needs WebGL/hardware acceleration; its existing
fallback screen remains when WebGL is unavailable.

Real human audio quality, physical-device touch feel, Safari/Firefox and sustained
low-power GPU performance remain manual. Deterministic local QA manipulates the
engine to test collisions/power-ups; hosted smoke checks use only visible controls.
Neither is a claim of human completion or a performance SLA.
